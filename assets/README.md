# DevJournal Assets

This directory contains the branding assets for **DevJournal**.

## Logo Files

| File | Purpose |
|------|---------|
| `logo-devjournal-appicon.svg` | App Icon source (512×512) — "J" journal motif with accent dot |
| `logo-devjournal-outlined.svg` | Outlined variant with inner frame |
| `logo-devjournal-wordmark.svg` | Horizontal logo with wordmark (2048×512) |
| `logo-devjournal-splash.svg` | Splash screen / App Store source (1024×1024) |

## Expo App Icons

> **Note:** Expo requires PNG images for `icon`, `adaptiveIcon`, and `favicon`.
> Convert the SVG sources to PNG using your preferred tool (e.g., Inkscape, Figma, or an online converter).
>
> - `icon.png` → 1024×1024 (from `logo-devjournal-splash.svg`)
> - `adaptiveIcon` foreground → 432×432 (from `logo-devjournal-appicon.svg`)
> - `favicon.png` → 32×32 or 48×48 (from `logo-devjournal-appicon.svg`)

## Design Rationale

- **Shape:** A stylized letter "J" formed from journal page lines — evoking a daily record, history, and stories.
- **Color:** Dark background (`#0A0A0A`) for consistency with the app's dark-first aesthetic.
- **Accent:** Indigo dot (`#6366F1`) as a modern tech-forward marker.
- **Typography:** System font stack for the wordmark — clean, modern, and platform-native.
